## Reflection

### How I Ensure My Code Is Functional and Secure
I use unit testing to verify that each requirement works as expected. I also include input validation to prevent invalid data from being stored or processed. By testing both valid and invalid scenarios, I reduce errors and improve reliability.

### How I Interpret User Needs
I carefully review requirements and break them down into specific rules the program must follow. I then write code and tests that directly match those rules to ensure everything works as intended.

### How I Approach Software Design
I start by understanding the requirements. Then I design small, focused classes with clear responsibilities. I keep the code organized and testable so that it is easier to maintain and improve.
